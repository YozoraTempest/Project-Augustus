# 游戏内容与发行

玩家提供自己合法取得的 EU4 游戏文件；DLC 按实际获得的许可使用。项目不提供原版程序、脚本、美术、音乐或 DLC 下载，也不将它们放入仓库和发行包。

本地游戏内容和生成缓存可放在已忽略的 `local-data/`、`local-cache/` 中。忽略规则不等于发行清单；发布时仍须排除原版内容、生成数据和个人路径。

项目自有代码采用 [GPL-3.0-only](../LICENSE)。第三方代码与资源保留各自的权利和许可，确认允许再分发后才能随项目发布。

发行版本应附带对应源码、许可材料和实际验证过的游戏、DLC 与 Mod 范围。未经验证的内容不得宣称兼容。当前文件工具的功能与限制见 [使用说明](EU4_CONTENT.md)。
