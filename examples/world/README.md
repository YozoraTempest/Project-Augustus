# 自制开局样本

这个小世界用于检查原版格式的输入、开局历史处理和 Godot 地图显示，不包含原版游戏内容。两个虚构国家、六个省份定义；固定地图只使用其中四个省份，另两个用于检查未使用的重复颜色。历史文件故意包含乱序日期、相同日期和未来条目，也包含自制的人物、外交、职位和建筑记录。商品目录、基础价格及两个相连的贸易节点用于检查数值精度、定义引用、历史增删与来源。

自制科技组与三条等级表用于检查基准开局等级和声明属性；第二个国家没有科技组，应保持未知。事件修正与重商主义历史用于检查精确小数、永久项增删和有限期限条目的报告，科技收益尚未执行。

静态修正、建筑与商品中的少量省份效果用于检查部分税收基数、人力贡献和来源说明。`defines.lua` 只有自制的直接数值声明；`native_attributes.json` 是独立写出的核心输入，与这套自制文件载入后得到相同状态。第二个陆地省份没有声明城市状态，计算必须保留这项未知，不能补为零或关闭其他缺项。

地区列表与自治历史用于检查地理归属、首都地区、历史追加值和未知的初始基值。自制最低自治规则为 35% 与 80%，用于确认规则来自输入；它们不是原版数值。`native_administration.json` 是独立编写的核心期望输入，和兼容入口产生相同状态。
