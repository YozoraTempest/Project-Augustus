# Event Popup

This self-authored content pack queues one country event for AAA during startup. It is used by the Godot integration test to exercise pending-event display, pausing, and option selection.

The title and first option use the pack's English localisation file. The missing description and second option retain their localisation keys. The separate [long event dialog sample](../event-dialog/README.md) exercises wrapping and scrolling with longer text.
