# 任务省份高亮演示

本目录为自制测试 Mod，配合 `examples/world` 和本目录的 `external_state.json` 使用。载入后展开国家任务区，点击任务行的“目标”，地图会标出当前匹配的省份。可以随时清除；任务面板折叠后仍可清除活动目标。

AAA 的“Survey the Border”最初标出省份1。推进一天后，事件将省份2转给AAA，目标随之变成1和2；选择事件后，省份1转给BBB，目标变成2。恢复此前快照会重新读取恢复后的归属。切换国家或重新载入世界会清除原活动目标。

政治地图的国家底色也会在归属改变后刷新，清除目标高亮时会显示当前国家的颜色。高亮不改变底图像素中的省份标识，仍可正常点击地图查看省份。

“Chart the Unknown Coast”同时包含已知目标与发现状态未决的省份；未决部分单独提示，不会伪装成已知没有目标。“Review the Unfinished Survey”的地图条件不受支持，但有效奖励仍可独立领取。目标查询不执行奖励、不登记完成、不消耗随机数，也不刷新已选任务树。

此界面按显式操作显示省份过滤结果；没有过滤内容的空块不提供地图目标按钮，显式 `always = yes` 才匹配全部省份。完成后的任务仍可查看其声明的目标。本示例不将这些界面约定声称为原版悬停或完成时机的复刻。

运行 `godot --headless --path godot --script res://tests/mission_province_highlights.gd` 执行界面回归。使用有图形设备的 Godot 运行相同脚本，并在 `--` 后提供 `--capture <绝对PNG路径>`，可生成最终界面截图。
